# Configuration reference

## kryptic.json

The per-repository project file. It contains no secrets and is committed to version
control. Every SDK finds it by walking up from the current working directory, so it
also works from subdirectories and monorepo packages.

```json
{
  "projectId": "proj_a1b2c3d4e5f6",
  "defaultEnvironment": "development"
}
```

<Properties>
  <Property name="projectId" type="string" required>
    The project's public id (`proj_` + 12 hex characters), shown on the project page in
    the dashboard. Identifies which project's secrets to fetch.
  </Property>
  <Property name="defaultEnvironment" type="string">
    The environment the daemon serves when nothing overrides it. Defaults to
    `development`.
  </Property>
</Properties>

## Environment variables (SDKs)

Every language SDK honors the same set. Environment variables always win over
`kryptic.json` and over options passed in code.

<Properties>
  <Property name="KRYPTIC_PROJECT_ID" type="string">
    Override the project id from kryptic.json.
  </Property>
  <Property name="KRYPTIC_ENV" type="string">
    Override the environment to fetch (e.g. `staging`).
  </Property>
  <Property name="KRYPTIC_SOCKET_PATH" type="string">
    Override the daemon endpoint. Default: `/tmp/kryptic-daemon.sock` on macOS,
    `$XDG_RUNTIME_DIR/kryptic-daemon.sock` on Linux, `\\.\pipe\kryptic-daemon` on
    Windows. Tests use this to point SDKs at a mock daemon.
  </Property>
  <Property name="KRYPTIC_TIMEOUT_MS" type="number">
    Daemon connection timeout in milliseconds. Default `2000`.
  </Property>
  <Property name="KRYPTIC_DISABLED" type="boolean">
    `true` force-disables injection everywhere, before any socket I/O.
  </Property>
  <Property name="KRYPTIC_SILENT" type="boolean">
    `true` suppresses the one-line warning when the daemon is absent.
  </Property>
</Properties>

<Note>
  SDKs are development-only by design. Each one checks its runtime's idiomatic
  environment signal and becomes a no-op outside development:

  - **Node.js:** `NODE_ENV` set to anything other than `development`
  - **.NET:** `ASPNETCORE_ENVIRONMENT` / `DOTNET_ENVIRONMENT` not `Development`
  - **Python / Go / Ruby / C++ / Rust / Java:** `production`, `prod`, or `staging` in
    the language's usual env vars (`RAILS_ENV`, `GO_ENV`, `RUST_ENV`, `SPRING_PROFILES_ACTIVE`, …)
</Note>

## Daemon and CLI

<Properties>
  <Property name="KRYPTIC_API" type="string">
    Point the daemon at a self-hosted (or local) Daemon BFF. Overrides the URL saved
    by `kryptic config set-api`. Default `https://daemon.kryptic.dev`. Local compose
    uses `http://localhost:5211`.
  </Property>
  <Property name="KRYPTIC_CLIENT_ID" type="string">
    Machine identity client id (`kmi_…`). Required by `kryptic ci export`.
  </Property>
  <Property name="KRYPTIC_CLIENT_SECRET" type="string">
    Machine identity client secret. Required by `kryptic ci export`. Shown once at
    creation in the dashboard.
  </Property>
  <Property name="KRYPTIC_PIPELINES_API" type="string">
    Override the Pipelines BFF URL used by `kryptic ci export`. Default
    `https://pipelines.kryptic.dev`. Self-hosted compose uses `http://localhost:5212`.
  </Property>
</Properties>
